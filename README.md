# مكتبة العلوم الرقمية — مدرسة محلاح للبنات (5–12)

منصة تعليمية وتطبيق ويب متكامل لإدارة واستعراض وتجربة الموارد العلمية التفاعلية والمحاكاة المخبرية وفق المناهج التعليمية المعتمدة في سلطنة عمان.

---

## الغرض من المشروع (Project Purpose)

توفير بيئة تعليمية تفاعلية آمنة لمعلمات وطالبات مدرسة محلاح للبنات (الصفوف 5–12) لاستكشاف التجارب العلمية التفاعلية (كيمياء، فيزياء، أحياء، علوم عامة)، وتحكيم الموارد الأكاديمية ونشرها مركزياً عبر قاعدة بيانات Supabase سحابية موحدة ومحمية بنظام أمان الصفوف (RLS).

---

## متطلبات التشغيل والتثبيت المحلي (Local Installation)

1. استنساخ المستودع:
```bash
git clone <repository_url>
cd maktabat-aloloom
```

2. تثبيت الحزم البرمجية:
```bash
npm install
```

---

## متغيرات البيئة المطلوبة (Required Environment Variables)

يتم ضبط المتغيرات التالية داخل ملف `.env` محلياً وفي إعدادات Vercel للإنتاج (بالأسماء فقط بدون تضمين أي مفاتيح سرية):

- `VITE_SUPABASE_URL`: رابط مشروع Supabase الأساسي.
- `VITE_SUPABASE_ANON_KEY`: المفتاح العام المعلن (Anon/Publishable Key) الخاص بـ Supabase لاستخدامه مع سياسات RLS.

## أوامر التشغيل والبناء (Commands)

- **بيئة التطوير (Development):**
```bash
npm run dev
```

- **فحص الأنواع والتوافق (Type Check):**
```bash
npx tsc --noEmit
```

- **بناء الإنتاج (Production Build):**
```bash
npm run build
```

---

## البنية المعمارية وقاعدة البيانات (Supabase Architecture)

- **Authoritative Database:**
  - `public.resources`: الجدول المعتمد والوحيد لموارد المكتبة التعليمية.
  - سياسات الأمان (Row Level Security - RLS):
    - القراءة متاحة للجميع (Public SELECT).
    - الإدراج والتعديل والحذف محصور حصرياً بالمدير المعتمد (`sciencelibrary8@gmail.com`).
- **المحاكاة التفاعلية (Sandboxed Execution):**
  - تشغيل كود HTML والمحاكاة التفاعلية داخل `iframe` معزول ومحمي بحاوية `sandbox="allow-scripts allow-forms allow-popups"` لمنع وصول المحتوى المشغل إلى الذاكرة المحلية أو بيانات الاعتماد للمنصة الرئيسية.

---

## ملاحظات النشر على Vercel (Deployment Notes)

- المشروع مهيأ للعمل كـ Single Page Application (SPA).
- ملف `vercel.json` يتضمن توجيه المسارات الداخلية `/(.*)` إلى `/index.html` لمنع أخطاء 404 عند تحديث الصفحة مباشرة.
